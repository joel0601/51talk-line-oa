1项目背景与目标

用户在完成注册后，我们希望将其承接进 LINE Official Account（LINE-OA） 这一私域渠道，通过 LINE-OA 的自动化能力完成「问好 → 挖需 → 简单问答 → 课前提醒 → 协助预约」，并在缺席后发起二次预约，从而替代/减轻人工外呼的重复工作，提升首节体验课（demo）出席率。

核心定位
LINE-OA 只负责「注册后 → 首节体验课出席」这一段旅程。出席即止；未出席则二次预约后结束。

销售分配采用分渠道差异化策略，最终目标是 100% 直接分配，每个真人销售都拥有 LINE-OA 坐席，可与用户、官方机器人三方同时协作。

关注数 ÷ 注册数

80%+

指标 / Metric 定义 / Definition 口径建议 / Note
关注率 / Follow Rate注册后 T+N 小时内关注 LINE-OA 的用户 ÷ 同期注册用户北极星指标，目标 80%+（泰国跑 1–2 周基线后校准）
关注转化率 / Follow CVR「AI 外呼引导」后成功关注数 ÷ 外呼触达数衡量外呼场景价值
预约率 / Booking Rate关注用户中完成首节体验课预约的占比衡量 LINE-OA 培育效果
出席率 / Attendance Rate预约用户中出席首节体验课的占比衡量提醒/预约质量
二次预约成功率 / Re-booking Rate缺席用户中二次预约成功的占比衡量挽留效果

目标 80% 参考来源：台湾市场（同为 LINE 主战区），仅在注册完成页曝光 LINE-OA、无 AI 外呼情况下的关注率。泰国因叠加「AI 外呼兜底」，理论上应高于 80%，建议以 80% 为起点、跑基线后上调。

5LINE-OA 官方建议 / Official Recommendations

5.1 关注方式（起步采用「标准三件套」）

方式 / Method说明 / Description定位 / Position
加好友短链 / 二维码 / LINE ID 搜索 短链 line.me/R/ti/p/@ID、lin.ee 二维码、@ID 搜索。短信/页面里只放短链+利益点，别让用户手动搜 ID。 起步采用
LINE Login + 自动加好友 注册流程内一次完成「注册+关注+ID 绑定」，返回 userId 精确归户，检测更实时。 后续增强（可选）
加友广告（CPF） LINE 官方广告，广告内直接放「加好友」按钮，按单次加好友成本出价。账号已认证（蓝盾），可用。 规模化拉新（可选）
通知消息（Notification Messages） 用户未加好友时经手机号匹配送达（需授权+内容经 LINE 审核，仅限通知类不可广告）。 泰国可用（已确认）

5.2 如何检测关注状态

  • Messaging API 的 follow / unfollow webhook 事件：用户加好友/删好友/解封时实时推送，follow.isUnblocked 可区分「首次关注」与「解除封锁」。
  • 当前账号已开通 Messaging API，直接接入 webhook 即可；若需「精确到具体注册用户」归户，需配合 LINE Login 的 userId 绑定（三件套起步阶段可按「好友总数」粗粒度比对）。

5.3 关键约束（务必提前规划）

⚠️ Messaging API 已开通 = 手动 1:1 聊天已关闭
当前账号已开通 Messaging API，意味着 LINE-OA 后台的「手动 1:1 聊天」已被永久关闭，改用 API 或官方 Manager。因此销售坐席必须通过第三方多坐席工具或 LINE「聊天进阶方案」实现，这是「100% 直接分配」终局形态的前置采购/选型项。
⚠️ 泰国 PDPA 合规
AI 外呼 + 短信 + LINE 消息均需用户同意（consent），外呼需 opt-in。详见第 7 节合规清单。

6各部门职责与意义 / Department Responsibilities

部门 / Dept 要做的事 / Responsibilities 意义 / Why It Matters
市场 Marketing ① 注册完成页「引导关注」物料与文案（短链/二维码/ID 搜索）；② 短信模板（短链+利益点）；③ 关注激励设计（如首课优惠）；④ 后续可选加友广告（CPF）。 关注率是北极星（目标 80%+），市场负责把「注册流量」高效转化为「关注流量」，是整条漏斗的入口。
产研 Product&Tech ① follow/unfollow webhook 接入与 CRM 用户 ID 绑定；② 自动化机器人（问好/挖需/问答/提醒/预约表单）；③ 5 分钟定时检测 + 外呼名单生成；④ 「关注提醒」自动化 AI 外呼场景搭建（新增独立场景，非真人）；⑤ 销售坐席系统选型（因 1:1 聊天已关闭）；⑥ 后续可选 LINE Login 接入。 技术底座。webhook 让「检测关注状态」实时可用；机器人与自动化外呼让 LINE-OA 承接自动化落地；坐席选型是终局形态的前置。
运营 Operations ① 关注率与漏斗指标监控（日报/看板）；② LINE-OA 话术/问答库/底部菜单/定时推送的内容运营；③ 非安卓 30/70 AB 测试设计与效果评估；④ 自动化 AI 外呼任务编排与名单管理（按渠道配置、5→15→30 重试、8:00–21:00 注册触发）；⑤ 缺席二次预约运营策略。 把各环节「串起来」并持续优化，是关注率、出席率提升的直接负责人。
销售 Sales ① 安卓：出席后承接分配；② 非安卓 30%：直接分配后电话通知用户加 LINE-OA 留存平台 + 销售私人 LINE 手动加用户；③ 非安卓 70%：抢新、打通号码后分配；④ 首节体验课出席跟进与转化（30% 直接分配组：销售与 LINE-OA 并行跟进）。终局：持有 LINE-OA 坐席与用户+机器人三方协作。 最终转化与签单。分配策略差异本质是「线索质量 vs 销售产能」的平衡，AB 测试用于验证哪种方式 ROI 更高。
数据 Data ① 关注率等指标埋点与口径定义；② 注册→关注→预约→出席→缺席 全漏斗看板；③ AB 测试显著性分析与归因；④ 分渠道关注率与外呼重试效果分析。 用数据验证「直接分配 vs 抢新」孰优，为 100% 直接分配决策提供依据。
合规/法务 Legal ① 泰国 PDPA 合规（AI 外呼 opt-in、短信/LINE 消息 consent、隐私告知）；② LINE 通知消息内容审核配合；③ 数据跨境与存储合规。 AI 外呼 + 多渠道触达是强监管场景，合规是「能上线」的前提，避免处罚与品牌风险。

7.2 合规清单（合规/法务侧）

  • AI 外呼 opt-in：注册时取得用户同意接收电话的授权；
  • 短信 / LINE 消息 consent：明确告知用途并留存同意记录；
  • PDPA：泰国个人数据保护法下的数据收集、存储、跨境与删除义务；
  • LINE 通知消息：内容需经 LINE 审核，仅限通知类不可广告。

8风险与待确认事项 / Risks & Open Items

已确认 / Confirmed
  • 关注方式起步 = 标准三件套（短链/二维码/ID 搜索）
  • 关注率目标 = 80%+（参考台湾仅完成页曝光、无外呼基线）
  • LINE OA 已认证蓝盾 + 已开通 Messaging API
  • 30% 直接分配触达 = 电话通知加 LINE-OA 留存平台 + 销售私人 LINE 手动加
  • 外呼口径 = 按渠道配置挑高转化渠道，5→15→30 分钟重试（自动化 AI 外呼，非真人）
  • LINE 通知消息泰国可用 = 确定可用
  • 外呼时区规则 = 仅泰国时间 8:00–21:00 注册的用户触发外呼（暂定）
待办 / Action Items
  • 销售坐席选型（最关键）：Messaging API 已开通导致 1:1 聊天关闭，需产研尽快选型第三方多坐席工具或 LINE「聊天进阶方案」，这是「100% 直接分配」的关键前置。
  • 「关注提醒」AI 外呼场景搭建：该场景尚未开始（7.1 已列「未开始」），需产研立项。
