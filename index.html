LINE-OA 关注承接与销售分配方案

泰国市场用户注册后的私域承接 · 授权绑定 · 自动化培育 · 分渠道销售分配
文档版本：v1.3（新增授权绑定环节） 日期：2026-08-19 涉及部门：市场 · 产研 · 运营 · 销售 · 数据 · 合规

1项目背景与目标

用户在完成注册后，承接进 LINE Official Account（LINE-OA） 私域渠道。用户关注 LINE-OA 后，需在欢迎语环节点击授权链接完成绑定，将 LINE 账号与公司 CRM 用户关联，之后 LINE-OA 才能通过自动化能力完成「问好 → 挖需 → 简单问答 → 课前提醒 → 协助预约」，并在缺席后发起二次预约，从而提升首节体验课（demo）出席率。

核心定位
LINE-OA 只负责「注册后 → 首节体验课出席」这一段旅程。出席即止；未出席则二次预约后结束。其中「授权绑定」是进入所有自动化培育与销售分配环节的硬前提。
关键机制 · 授权绑定
用户关注 LINE-OA 只代表「成为好友」，CRM 此时仅拿到 LINE userId，尚无法对应到具体注册用户。必须由 LINE-OA 在欢迎语推送授权链接，用户点击授权后，才完成 LINE userId ↔ CRM 用户 ID 绑定。不授权 = 无法与 CRM 关联。

销售分配采用分渠道差异化策略，最终目标是 100% 直接分配，每个真人销售都拥有 LINE-OA 坐席，可与用户、官方机器人三方同时协作。

目标值说明：台湾市场「仅完成页曝光、无授权环节」的关注率为 80%。泰国新增授权绑定环节，CRM-LINE 有效绑定率 = 关注率 × 授权入口点击率 × 授权成功率 × 绑定成功率，会明显低于 80%，因此目标待跑 1–2 周基线后校准，不宜直接沿用 80%。

5.1 关注方式（起步采用「标准三件套」）

方式 / Method说明 / Description定位 / Position
加好友短链 / 二维码 / LINE ID 搜索 短链 line.me/R/ti/p/@ID、lin.ee 二维码、@ID 搜索。短信/页面里只放短链+利益点，别让用户手动搜 ID。 起步采用
授权绑定（欢迎语推链接） 关注后在欢迎语推授权链接（LIFF + LINE Login），用户点击授权后完成 LINE userId ↔ CRM 用户 ID 绑定。 必须（关键前提）

5.2 授权绑定与状态检测

  • 授权绑定：关注 LINE-OA 仅能通过 follow webhook 拿到 LINE userId，无法对应 CRM 注册用户；需用户在欢迎语点击授权链接（LIFF + LINE Login）完成绑定，CRM 才能精确归户。
  • 状态检测：通过 follow webhook 事件 + 授权绑定记录共同判断「已授权 / 未授权」两态。follow.isUnblocked 可区分「首次关注」与「解除封锁」。

5.3 关键约束（务必提前规划）

⚠️ Messaging API 已开通 = 手动 1:1 聊天已关闭
当前账号已开通 Messaging API，意味着 LINE-OA 后台的「手动 1:1 聊天」已被永久关闭，改用 API 或官方 Manager。因此销售坐席必须通过第三方多坐席工具或 LINE「聊天进阶方案」实现，这是「100% 直接分配」终局形态的前置采购/选型项。
⚠️ 泰国 PDPA 合规
AI 外呼 + 短信 + LINE 消息 + 授权绑定均需用户同意（consent），外呼需 opt-in。详见第 7 节合规清单。

产研 Product&Tech ① 欢迎语授权链接（LIFF + LINE Login）开发，完成 LINE↔CRM 绑定；② follow/unfollow webhook 接入 + 授权绑定记录；③ 自动化机器人（问好/挖需/问答/提醒/预约表单）；④ 5 分钟定时检测授权状态 + 外呼名单生成；⑤ 「关注提醒」自动化 AI 外呼场景搭建（非真人）；⑥ 销售坐席系统选型（因 1:1 聊天已关闭）。 技术底座。授权绑定是「CRM 能识别用户」的关键，没有它后续一切无法精确到人；机器人、检测、外呼都是自动化承接的支撑。
运营 Operations ① 绑定率与漏斗指标监控（日报/看板）；② 欢迎语/授权引导话术 + LINE-OA 话术/问答库/底部菜单/定时推送内容运营；③ 非安卓 30/70 AB 测试设计与效果评估；④ 自动化 AI 外呼任务编排与名单管理（按渠道配置、5→15→30 重试、8:00–21:00 注册触发）；⑤ 缺席二次预约运营策略。 把各环节「串起来」并持续优化，是绑定率、出席率提升的直接负责人。
销售 Sales ① 安卓：出席后承接分配；② 非安卓 30%：直接分配后电话通知用户加 LINE-OA 留存平台 + 销售私人 LINE 手动加用户；③ 非安卓 70%：抢新、打通号码后分配；④ 首节体验课出席跟进与转化（30% 直接分配组：销售与 LINE-OA 并行跟进）。终局：持有 LINE-OA 坐席与用户+机器人三方协作。 最终转化与签单。分配策略差异本质是「线索质量 vs 销售产能」的平衡，AB 测试用于验证哪种方式 ROI 更高。
数据 Data ① CRM-LINE 有效绑定率等指标埋点与口径定义；② 注册→关注→绑定→预约→出席→缺席 全漏斗看板；③ AB 测试显著性分析与归因；④ 分渠道绑定率与外呼重试效果分析。 用数据验证「直接分配 vs 抢新」孰优，为 100% 直接分配决策提供依据。
合规/法务 Legal ① 泰国 PDPA 合规（AI 外呼 opt-in、短信/LINE 消息/授权 consent、隐私告知）；② LINE 通知消息内容审核配合；③ 数据跨境与存储合规。 AI 外呼 + 多渠道触达 + 授权绑定是强监管场景，合规是「能上线」的前提，避免处罚与品牌风险。

7.2 合规清单（合规/法务侧）

  • AI 外呼 opt-in：注册时取得用户同意接收电话的授权；
  • 短信 / LINE 消息 / 授权绑定 consent：明确告知用途并留存同意记录；
  • PDPA：泰国个人数据保护法下的数据收集、存储、跨境与删除义务；
  • LINE 通知消息：内容需经 LINE 审核，仅限通知类不可广告。

8风险与待确认事项 / Risks & Open Items

已确认 / Confirmed
  • 关注方式起步 = 标准三件套（短链/二维码/ID 搜索）
  • 北极星指标 = CRM-LINE 有效绑定率（完成有效绑定的用户 ÷ 注册用户）
  • 状态两态 = 已授权 / 未授权；关注但未点授权 = 未授权
  • 未授权用户统一由自动化 AI 外呼提醒（非真人，5→15→30 重试）
  • LINE OA 已认证蓝盾 + 已开通 Messaging API
  • 30% 直接分配触达 = 电话通知加 LINE-OA 留存平台 + 销售私人 LINE 手动加
  • LINE 通知消息泰国可用 = 确定可用
  • 外呼时区规则 = 仅泰国时间 8:00–21:00 注册的用户触发外呼（暂定）
待办 / Action Items
  • 欢迎语授权链接（LIFF + LINE Login）开发：这是绑定率的前提，尚未开始，需产研立项（优先级最高）。
  • 销售坐席选型（关键）：Messaging API 已开通导致 1:1 聊天关闭，需产研选型第三方多坐席工具或 LINE「聊天进阶方案」。
  • 「关注提醒」自动化 AI 外呼场景搭建：该场景尚未开始，需产研立项。
  • 有效绑定率目标值：CRM-LINE 有效绑定率 < 关注率，不能沿用台湾 80%，需跑 1–2 周基线后校准。
