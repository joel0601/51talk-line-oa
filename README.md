## 方案概要

用户在注册后承接进 LINE Official Account（LINE-OA）私域渠道，通过自动化能力完成「问好 → 挖需 → 问答 → 课前提醒 → 协助预约」，并在缺席后发起二次预约，提升首节体验课（demo）出席率。

- **北极星指标**：LINE-OA 关注率（目标 80%+）
- **关注方式**：标准三件套（短链 / 二维码 / LINE ID 搜索）起步
- **兜底**：注册 5 分钟后检测关注状态，未关注则自动化 AI 外呼引导（5→15→30 分钟重试，仅泰国时间 8:00–21:00 注册触发）
- **销售分配**：安卓出席后分配；非安卓 30% 直接分配 + 70% 抢新（AB 测试）
- **终局**：100% 直接分配，每个销售拥有 LINE-OA 坐席，与用户 + 官方机器人三方协作
- **涉及部门**：市场 / 产研 / 运营 / 销售 / 数据 / 合规
